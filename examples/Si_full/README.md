# Si_full — silicon point-defect workflow example

This directory is a **scaffold** for a 7-stage point-defect VASP workflow on
silicon. The plan.yaml is fully populated and validates against the JSON
Schema; the POSCAR is real; everything else is empty pending VASP runs.

## What's here

```
Si_full/
├── plan.yaml                                # Schema-valid, ready to run
├── unitcell/
│   └── structure_opt/
│       ├── POSCAR                           # Primitive Si (2 atoms, 5.43 Å)
│       └── POSCAR_conventional              # 2x2x2 of primitive (16 atoms)
├── cpd/                                     # Stage 2 output goes here
├── defect/                                  # Stages 3-7 outputs go here
└── results/                                 # Final formation energy plots
```

## What's NOT here (and why)

This directory does **not** contain any VASP outputs (vasprun.xml, OUTCAR,
CONTCAR, calc_results.json, formation-energy plots, etc.) because those
require real VASP runs on a SLURM cluster with a working POTCAR set. We
don't fabricate those results; the project should validate end-to-end on
a system with VASP available.

## How to run

### 1. Validate the plan

```bash
pydefect-run plan . --validate
# or
python -c "from pydefect_auto.plan import validate; from pydefect_auto.config import load_plan; \
    info, raw = load_plan('.'); print(validate(raw))"
```

Expected output: `plan.yaml 校验通过` (or empty list from validate()).

### 2. Re-generate plan (optional, to test the pipeline)

```bash
pydefect-run plan . --obj Si --poscar ./unitcell/structure_opt/POSCAR --encut 318 --force
```

This will run the inference chain: POSCAR check, ENCUT detection, DFT+U
check, defect inference, POTCAR variant query. The output `plan.yaml` may
differ from the hand-written one in minor ways (POTCAR variants, etc.).

### 3. Run the 7-stage pipeline

```bash
# Non-interactive (recommended in scripts/CI):
pydefect-run run . --auto

# Interactive (will prompt for confirmation at each step):
pydefect-run run .
```

To run a single stage:

```bash
pydefect-run stage 1 .   # unitcell only
pydefect-run stage 5 .   # post-processing only (after VASP completes)
```

### 4. Inspect the workflow

```bash
pydefect-run check . --verbose
```

This shows which stage outputs exist (e.g. `Stage 1: done` if
`unitcell/unitcell.yaml` is present).

## Silicon-specific notes

- **POTCAR**: Si has variants `Si` (default) and `Si_sv` (semicore).
  The example uses `Si`. If your POTCAR set has only `Si_sv`, override
  in plan.yaml: `pp: [Si_sv]`.
- **ENCUT**: Si POTCAR ENMAX ≈ 245 eV → 1.3× ≈ 318 eV. Override
  `parameters.encut` if you use a different variant.
- **Vacancy charge states**: Si vacancy is a textbook case. Common
  charge states: 0, ±1, ±2. Other systems may need different ranges.
- **Supercell size**: 64-atom (2x2x2 of conventional) is typical for Si.
  The `max_atoms: 600` upper bound in plan.yaml just prevents runaway
  supercells for more complex systems.

## Differences from examples/Si and examples/Si_test

`examples/Si/` and `examples/Si_test/` are *minimal* placeholders that
contain only a structure_opt/POSCAR. They exist for documentation
purposes — see the README at the repo root for context.

This `Si_full/` directory is a *complete scaffold*: real POSCAR +
schema-valid plan.yaml + expected directory layout, ready for a real
VASP run.
