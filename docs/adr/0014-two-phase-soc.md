# ADR 0014 — 两阶段 SOC 计算策略（先非 SOC 收敛，再补 SOC）

- 状态：已接受（2026-08-10）
- 关联：ADR 0012（+U 永远打开）、ADR 0010（链式播种）、crisp_light#137（tag 归分区，暂缓）

## 背景

5 个 Bi 掺杂体系（Gd2GaSbO7:Bi/La2SrSc2O7/La2Zr2O7/Y2Sn2O7/Y2Ti2O7）当前全部以 LSORBIT 直接 SOC 计算。SOC 电子步成本高（实测 ~9min/离子步，64 核 88 原子），且 83% 的缺陷不含 Bi——Bi 的 SOC 影响只在含 Bi 的缺陷上显著。直接全 SOC 是对不含 Bi 计算的浪费。

## 决策

两阶段 SOC 策略（**一般化**——适用于所有体系）：

1. **阶段 1**：所有计算先以**非 SOC**（无 LSORBIT）跑完——结构优化、链式播种、形成能主链路。
2. **阶段 2**（非 SOC 收敛后补算）：
   - **含 Bi 的目录**（目录名 `Bi_*` 前缀）：**SOC 续算**——LSORBIT 开 + 从 CONTCAR 续、继续优化（结构也 SOC 化）。
   - **不含 Bi 的目录**：**SOC 单点**（NSW=0）——一次 SOC 能量修正。
3. **执行纪律**：单体系串行推进（按完成度排序），不批量铺开；不破坏已算成果（已收敛/在算的保留，未算的按新方案）。
4. 机制代码先做（阶段 2 自动触发），CaAl4O7 收尾后实施。

## 范围

- defect + cpd（含 Bi 相）+ unitcell（band/dos/dielectric）全部适用。
- 无 SOC 需求的体系（Fe 掺杂等）阶段 2 无操作。

## 代价与风险

- 阶段 2 的口径混合风险：已算的（SOC）与未算的（两阶段）并存——SOC 单点/续算能量与直接 SOC 能量可比（同为 SOC 总能量），结构差异 <1%。
- 严格按目录名 `Bi_*` 判定——Gd2GaSbO7:Bi 中含 Gd 不含 Bi 的缺陷（如 Va_Gd）也走单点（Gd 的 f 电子 SOC 修正丢失，已接受）。
- 2026-08-10 曾误操作（INCAR 去 SOC 605 个 + cancel 36 个）——按用户指示**保持现状不回滚**，两阶段实施时统一处理。
