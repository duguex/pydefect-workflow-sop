# vasp-sop interactive report — Playwright verification (conda playwright)

For verifying `formation_energy_interactive.html` (generated by `vasp_sop/report/interactive.py`) behaviorally: docked readout, μ/oxidation rows, Fermi line, wheel scroll.

## Why not xd://browser
The shared browser daemon is often unavailable on this host (`hub ps` shows no omp.browser daemon). Fallback that works: the conda playwright install (`/home/duguex/.conda/envs/dgkan_rocm_3.11/bin/playwright`), driven from an eval cell with **top-level await** — `asyncio.run()` fails inside the eval runner's running loop.

## Recipe
1. Regenerate the report first (`vasp-sop report <system_dir> --interactive` from `/home/duguex/vasp_sop`).
2. In an eval cell:
   ```python
   from playwright.async_api import async_playwright
   pw = await async_playwright().start()
   browser = await pw.chromium.launch(headless=True, args=["--no-sandbox"])
   page = await browser.new_page(viewport={"width": 1280, "height": 900})
   errors = []
   page.on("pageerror", lambda e: errors.append(str(e)))  # always wire this
   await page.goto("file://<abs-path>/formation_energy_interactive.html")
   ```
3. Always `file://` (iframe frames have no `.mouse`; iframe coordinates also skew page-level math).
4. Dock the readout: compute FE canvas center via `getBoundingClientRect()` **after** `goto` (measuring before goto → null canvas), then `page.mouse.move(x, y)` and wait ~120ms.
5. Sweep E_F: iterate `page.mouse.move` over plot fractions, then assert via `page.evaluate`.

## Gotchas (each cost a debug round)
- **No lambdas across evaluate**: `page.evaluate(lambda…)` / functions-as-args fail (`fn is not a function`). Pass string expressions or serializable data; implement matching inside the evaluated JS.
- **Measure geometry after navigation**: `document.getElementById('cv').getBoundingClientRect()` returns null if the page hasn't loaded the report yet — goto first, then measure.
- **Panel content = visible defects only**: rows come from `fillTip` at the cursor's E_F; shallow defects (pydefect `allow_shallow=False`) are filtered at generation — a missing expected row may be a shallow defect, not a bug. Check `defect_energy_summary.json` `is_shallow`.
- Readout is display state: assert `calcRow(name,curMu,cursorEF).q` agrees with the displayed `μ` via `MAG[name][q]` (stable charge state), not against the plot.
- Wheel scroll test: `page.mouse.wheel(0, 400)` then read `tip.scrollTop` (only matters when content exceeds the viewport cap).

## Cleanup
Always `await browser.close()` and `await pw.stop()` at the end.
